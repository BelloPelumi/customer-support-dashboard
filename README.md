# Customer Support Dashboard

## 📌 Project Overview
This project analyzes customer support operations using Microsoft Excel. The dashboard provides insights into ticket volume, customer satisfaction, resolution performance, and overall support efficiency through interactive visualizations.

## 🎯 Objectives
- Monitor customer support performance.
- Analyze ticket resolution trends.
- Evaluate customer satisfaction.
- Identify opportunities to improve service delivery.

## 🛠️ Tools Used
- Microsoft Excel
- Power Query
- PivotTables
- Pivot Charts
- Slicers

## 📊 Key Performance Indicators (KPIs)
- Total Tickets
- Resolution Rate
- Average Customer Satisfaction
- Feedback Rate

## 🧹 Data Preparation
The dataset was cleaned and transformed using Power Query by:
- Removing unnecessary columns
- Handling missing values
- Creating Month, Year, and Quarter columns
- Creating Age Group and Customer Satisfaction categories
- Formatting date fields for analysis

## 📈 Dashboard Features
- Interactive filters using slicers
- Ticket trends over time
- Customer satisfaction analysis
- Resolution status analysis
- Customer demographic insights

## 💡 Key Insights
- Identified periods with higher ticket volumes.
- Measured overall ticket resolution performance.
- Evaluated customer satisfaction across different groups.
- Highlighted trends that can support better customer service decisions.
